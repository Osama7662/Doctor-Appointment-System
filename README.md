# Doctor Appointment System 🏥

A full-stack Doctor Appointment Management System developed using **Java, Spring Boot, Microservices Architecture, MySQL, and Angular**.

The application aims to simplify the process of managing doctor appointments by providing separate functionalities for patients, doctors, and administrators.

## 🚀 Technologies Used

**Backend:**
- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- JWT Authentication
- Hibernate
- REST APIs
- ModelMapper

**Database:**
- MySQL

**Frontend:**
- Angular
- TypeScript
- HTML
- CSS

## ⚙️ Core Features

- User registration and login
- JWT-based authentication
- Role-based user management
- Doctor profile management
- Doctor approval and rejection workflow
- Appointment booking
- Appointment status management

## 🏗️ Architecture

The project follows a Microservices Architecture with independently developed services:

- User Service
- Doctor Service
- Appointment Service

Each service is designed with its own responsibilities and database.

## 🎯 Project Objective

To build a scalable and maintainable healthcare appointment management application while gaining practical experience in Java backend development, Spring Boot, REST API development, database management, microservices architecture, and Angular frontend development.

## 📌 Project Status

Currently under development. New features and improvements are being added progressively.
